## 视觉设计

面向买广东特产、家乡味和中秋伴手礼的人。首图的任务是让买家在手机缩略图里认出白土月饼和红豆口味；后续图片分别回答馅料、数量、工艺和送礼问题。

这套的识别点是实物粗大压印与深色红豆切面的并置。首图让有压印的半块与切面靠在一起，占据大部分画面，金色内托保留一点边缘。它既能对应真实商品，也能区别于红礼盒占满画面的主图。

### 构图选择与自检

考虑过礼盒居中、包装与切面并列、切面占主导三种方案。礼盒居中会弱化口味；并列同等大小容易像拼贴。本套首图采用切面占主导，独立包装图留到后面，减少信息竞争。

```text
首图、切面图                  规格、礼盒图
┌────────────────┐           ┌────────────────┐
│ 大标题         │           │ 大标题         │
│ 一句短副文案   │           │ 一句规格/配件  │
│                │           │                │
│   饼面＋切面   │           │  单个完整盒组  │
│   一个大主体   │           │  数量看得清楚  │
└────────────────┘           └────────────────┘
```

暖棕与宋体本身不足以构成差异。真正需要保持的是本商品压印、豆沙切面、金托和包装标识。删除与产品无关的月宫、桂花、烟雾、灯笼和泛黄古纸，不靠堆中秋符号制造家乡感。

## 每次生成都必须遵守的实物约束

1. 只用红豆目录中的原始实拍作商品参考。已有生成主图、详情图及其他口味只可用于理解排版，不能拿来定义红豆月饼外观。
2. 饼面是明亮、略油润的金棕色，凹处偏灰黄，上色不完全均匀。把压印当成一整套模具图形保留，包括分区、笔画、间距和深浅；不要识别成文字后重新排字，不改成规整迷宫花纹或厚侧壁齿轮饼。
3. 红豆沙为深灰紫褐色，压实细密，有自然刀痕和细碎屑。不得变成巧克力、蛋糕、整粒红豆、五仁、莲蓉、蛋黄或流心。饼皮厚度按实拍，不能为了突出馅多而缩薄饼皮。
4. 单枚包装保留上方金红方形标识、下方门楼图案与白土月饼字样，并保持原本比例、位置、膜面反光与透视。不能生成第二个同样的标签、放大标识或替换新包装。需要包装时优先沿用实拍主体合成。
5. 黄色内盒为四格四枚。规格图不另加裸饼，避免画面像买四送一。礼袋、餐具已确认附带，但无清晰款式实拍，仅写文案。
6. 光线以柔和侧光为主，暖背景不等于给食品加黄滤镜。禁止悬浮、强光边、湿亮糖浆、塑料质感和复制粘贴式纹理。
7. 每条提示词生成无新增宣传文字底图，再按对应文案可靠排字；实物包装原有印刷应保留。中文生成不准确时，不能用近似字蒙混交付。
8. 生成不能保证像素级保真。饼面压印、颜色、比例或包装一旦与实拍明显不同，该图退回修正，不能用“图片仅供参考”替代实物核验。
