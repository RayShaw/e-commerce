# 广东韶关白土月饼-五仁淘宝主图提示词

## 设计目标

面向想买广东特产、家乡味和中秋伴手礼的人。搜索缩略图先看清月饼，再看懂一个卖点。主打“韶关白土、老式五仁、非遗技艺、柴火烤制”，不做满屏红色、大促字体和虚假豪华礼盒。

商品信息统一为：125g/枚，4枚/盒，净含量500g，保质期25天，生产方为韶关市曲江区白土供饼厂，随盒附礼袋和餐具。

“非遗技艺”“柴火烤制”正式上架前应保留证明或生产资料。没有作坊实拍时，不虚构师傅、柴火灶、牌匾或证书。

## 真实外观硬标准

1. 独立包装必须参考 ../../素材/广东韶关白土月饼-五仁/五仁白土月饼透明金色包装正面.jpg。每包有两处标识：上方是较小的金红方形“白土供饼”标签，宽度约为饼体直径的三分之一；下方是红金门楼徽章及“白土月饼”字样。两处都必须保留，并贴合塑料膜的透视和反光。优先抠取实拍包装再合成，不让模型重画标签。
2. 裸饼呈自然深金棕色，边缘略深。饼面压印必须把实拍包装图中的整套模具纹路作为不可拆分的图形参考，花边、边框、分区、压印笔画、间距和比例全部照实物保留。不得把压印理解成普通文字后重新排版，也不得增删或简化纹路。
3. 切面是紧实老式五仁馅，可见大小不一的果仁和籽仁。不得出现蛋黄、莲蓉、奶黄、流心或拉丝。
4. 黄色内盒严格对应4枚。展示切面时，切开的样品必须明确是盒内其中1枚。
5. 红色荷花礼盒与黄色内盒按实拍还原。素材未清楚展示礼袋、餐具，因此只写文案，不虚构具体款式。

## 统一视觉系统

| 色彩角色 | 色值 | 用途 |
|---|---:|---|
| 白土深棕 | #2B170F | 背景与标题 |
| 柴火暖棕 | #6F3E24 | 木桌与阴影 |
| 烤皮金黄 | #D7A44C | 月饼与数字重点 |
| 旧纸米色 | #E8D5AD | 信息封带 |
| 荷花暗红 | #8A3028 | 呼应真实礼盒 |
| 蒸汽乳白 | #F6EAD2 | 副文案 |

- 主标题：思源宋体 Heavy 或方正宋黑，像老饼铺招牌。
- 副文案：思源黑体 Medium 或苹方 Medium。
- 规格数字：DIN Condensed Bold 或思源黑体 Heavy。
- 固定识别元素：主图1至5各保留一条窄幅“白土纸封带”，取自礼盒浅色封签的感觉。
- 光线：3600K至4200K暖光，保留包装反光、饼皮裂纹、切面碎屑和接触阴影。

初版若只用暖棕、宋体和中秋礼盒，仍像常见节庆模板。最终用真实金红“白土供饼”标签、白土纸封带和深棕大留白建立识别度，让红色只来自实物礼盒。
